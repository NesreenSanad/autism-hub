# Frontend (Next.js)

Web app for families: search the directory by governorate, service and name, in Arabic (RTL) and English. Works as a PWA on phones.

Not scaffolded yet. To start it:

```bash
npx create-next-app@latest . --typescript --app --eslint --src-dir
```

It will read data from the backend API (`NEXT_PUBLIC_API_URL`).
